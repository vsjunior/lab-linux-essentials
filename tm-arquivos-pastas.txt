1. CONCEITOS BÁSICOS
═══════════════════════════════════════════════════════════════════════════════════

O QUE É ESPAÇO EM DISCO?

Disco = HD/SSD onde ficam seus arquivos

Capacidade total: 500GB, 1TB, etc

Usado: Quanto está ocupado
Livre: Quanto ainda pode usar

⚠️ Quando livre < 10%, sistema fica lento!

ARQUIVOS GRANDES:
├─ Vídeos (1GB cada)
├─ ISOs (4GB cada)
├─ Jogos (10GB cada)
├─ Fotos (alta resolução)
└─ Downloads antigos

PASTAS GRANDES:
├─ ~/Videos/
├─ ~/Downloads/
├─ ~/.cache/
├─ /var/log/
├─ /usr/share/
└─ /home/usuario/

DUPLICATAS:
├─ Mesmo arquivo em 2 lugares
├─ Fotos duplicadas
├─ Downloads repetidos
├─ Backups antigos
└─ Versões diferentes do mesmo arquivo

2. VER ESPAÇO TOTAL DO SISTEMA
═══════════════════════════════════════════════════════════════════════════════════

VER TODOS OS DISCOS:
────────────────────

df -h

Resultado:
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1       500G  450G   50G  90%  /           ← ⚠️ CHEIO!
/dev/sda2       100G   10G   90G  10%  /home       ← OK
tmpfs           7.8G     0  7.8G   0%  /tmp        ← RAM

ENTENDER:
├─ Size: Capacidade total
├─ Used: Espaço usado
├─ Avail: Espaço disponível
├─ Use%: Porcentagem usada
└─ Mounted on: Onde está montado

⚠️ Se Use% > 85%, precisa limpar!


VER SÓ O DISCO PRINCIPAL:
──────────────────────────

df -h /

Resultado:
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1       500G  450G   50G  90%  /

✅ Fácil de ver se está cheio

9. SCRIPTS AUTOMÁTICOS PARA LIMPEZA
═══════════════════════════════════════════════════════════════════════════════════

SCRIPT: RELATÓRIO DE ESPAÇO:
────────────────────────────

cat > ~/relatorio-espaco.sh << 'EOF'
#!/bin/bash

echo "=== RELATÓRIO DE ESPAÇO EM DISCO ==="
echo ""

echo "DISCO PRINCIPAL:"
df -h /
echo ""

echo "TOP 10 PASTAS MAIORES:"
du -sh ~/* 2>/dev/null | sort -rh | head -10
echo ""

echo "TOP 10 ARQUIVOS MAIORES:"
find ~ -type f -exec du -h {} + 2>/dev/null | sort -rh | head -10
echo ""

echo "ARQUIVOS > 1GB:"
find ~ -type f -size +1G -exec du -h {} + 2>/dev/null | sort -rh
echo ""

echo "DUPLICATAS (se fdupes instalado):"
fdupes -r ~ 2>/dev/null | wc -l | xargs echo " arquivos duplicados encontrados"
echo ""

echo "ARQUIVOS ANTIGOS (> 1 ano):"
find ~ -type f -mtime +365 2>/dev/null | wc -l | xargs echo " arquivos antigos encontrados"

EOF

chmod +x ~/relatorio-espaco.sh

Usar:
./relatorio-espaco.sh


SCRIPT: LIMPEZA AUTOMÁTICA:
────────────────────────────

cat > ~/limpeza-automatica.sh << 'EOF'
#!/bin/bash

echo "=== LIMPEZA AUTOMÁTICA DE ESPAÇO ==="

# Confirmação
read -p "Isso vai deletar arquivos antigos. Continuar? (s/n): " confirm
if [ "$confirm" != "s" ]; then exit 1; fi

echo "Limpando Downloads antigos (> 30 dias)..."
find ~/Downloads -type f -mtime +30 -delete 2>/dev/null

echo "Limpando arquivos temporários..."
rm -rf /tmp/* 2>/dev/null
rm -rf ~/.cache/thumbnails/* 2>/dev/null

echo "Limpando lixeira..."
rm -rf ~/.local/share/Trash/* 2>/dev/null

echo "Limpando logs pessoais (> 90 dias)..."
find ~ -name "*.log" -mtime +90 -delete 2>/dev/null

echo "✅ LIMPEZA CONCLUÍDA!"
df -h /

EOF

chmod +x ~/limpeza-automatica.sh

Usar:
./limpeza-automatica.sh

11. PLANO DE AÇÃO PARA LIBERAR ESPAÇO
═══════════════════════════════════════════════════════════════════════════════════

PASSO 1: DIAGNOSTICAR
──────────────────────

df -h /                                    # Ver se está cheio
du -sh ~/* | sort -rh | head -10          # Top pastas

PASSO 2: IDENTIFICAR O QUE DELETAR
───────────────────────────────────

✅ Downloads antigos
✅ Vídeos assistidos
✅ ISOs de instalação
✅ Backups antigos
✅ Cache de programas
✅ Arquivos temporários

❌ Documentos importantes
❌ Fotos pessoais
❌ Configurações
❌ Programas instalados

PASSO 3: FAZER BACKUP ANTES
───────────────────────────

tar -czf backup-importante.tar.gz ~/Documentos/ ~/Imagens/

Resultado:
├─ Backup seguro
├─ Pode recuperar se errar
└─ Comprimido

PASSO 4: DELETAR COM CAUTELA
─────────────────────────────

rm ~/Downloads/ubuntu.iso                 # ISO antigo
rm ~/Videos/filme-assistido.mp4           # Vídeo visto

12. PERGUNTAS FREQUENTES
═══════════════════════════════════════════════════════════════════════════════════

P: Como saber se meu disco está cheio?
R: df -h / → Se Use% > 85%, precisa limpar

P: Onde ficam os arquivos maiores?
R: ~/Videos/, ~/Downloads/, ~/.cache/

P: Como encontrar duplicatas?
R: sudo apt install fdupes -y; fdupes -r ~

P: É seguro deletar ~/.cache/?
R: Geralmente sim, programas recriam. Mas teste primeiro

P: Como comprimir arquivos grandes?
R: tar -czf arquivo.tar.gz pasta-grande/

P: Como mover para HD externo?
R: mv ~/Videos/ /media/HD-externo/

P: Como automatizar limpeza?
R: Criar script e adicionar no crontab

P: find está demorando muito?
R: Use -maxdepth 2 para limitar profundidade

P: Como ver progresso do find?
R: find ~ -type f -print0 | xargs -0 du -h | sort -rh

P: Errei e deletei arquivo importante?
R: testdisk ou extundelete podem recuperar (difícil)
