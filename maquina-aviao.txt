1. CONCEITOS - POR QUE MÁQUINA FICA LENTA?
═══════════════════════════════════════════════════════════════════════════════════

RAZÕES PRINCIPAIS:

Lixo acumulado:
├─ Arquivos temporários (/tmp)
├─ Cache de programas
├─ Histórico desnecessário
├─ Duplicatas de downloads
└─ "Restos" de desinstalações

Muitos programas rodando:
├─ Serviços desnecessários
├─ Startups auto-iniciam
├─ Processos em background
├─ Consumindo RAM

Disco cheio:
├─ Sistema operacional lento com disco cheio
├─ Cache não comprimido
├─ Logs gigantes
└─ Arquivos antigos


RESULTADO:

❌ Máquina lenta
❌ Internet travada
❌ Navegação difícil
❌ Sistema irresponsivo

✅ OBJETIVO: Deixar tudo limpo e rápido!

2. VERIFICAÇÃO INICIAL - DIAGNOSTICAR O PROBLEMA
═══════════════════════════════════════════════════════════════════════════════════

VER ESPAÇO EM DISCO:
───────────────────

df -h

Resultado:
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1       500G  450G   50G  90%  /           ← ⚠️ CHEIO!
/dev/sda2       100G   10G   90G  10%  /home       ← OK

Se Use% > 80%, disco está muito cheio!


VER MEMÓRIA RAM:
────────────────

free -h

Resultado:
               total        used        free      shared  buff/cache
Mem:            15Gi       8.5Gi       2.3Gi       1.2Gi       4.7Gi
Swap:           2.0Gi       0.5Gi       1.5Gi

⚠️ Used > 80% = pouca memória livre
✅ Free > 20% = OK


VER PROCESSOS PESADOS:
──────────────────────

ps aux --sort=-%mem | head -10

Resultado:
USER     PID %CPU %MEM     VSZ    RSS COMMAND
root       1  0.0  0.1  19356  2892 init
usuario 1234 45.2  15.3 2456M 2450M firefox    ← Comendo muita RAM!
usuario 5678  8.5   8.2 1234M 1300M chrome
usuario 9012  2.1   4.5  567M  720M python

⚠️ Processos usando > 10% cada podem ser problema


VER PROCESSOS RODANDO:
──────────────────────

systemctl list-units --type=service --state=running

Resultado:
UNIT                           LOAD   ACTIVE SUB     DESCRIPTION
accounts-daemon.service        loaded active running Accounts Service
bluetooth.service              loaded active running Bluetooth service
cups.service                   loaded active running Cups Printing Service
... (muitos mais)

💡 Alguns você pode desativar

3. PASSO 1 - LIMPEZA DE CACHE
═══════════════════════════════════════════════════════════════════════════════════

LIMPAR CACHE DO SISTEMA:
────────────────────────

sync                                        # Sincronizar disco

sudo sysctl -w vm.drop_caches=3

Resultado:
├─ Libera cache não usado
├─ RAM fica disponível
└─ Pode ficar um pouco lento por segundos

⚠️ Seguro usar


LIMPAR CACHE APT (Debian/Ubuntu):
──────────────────────────────────

sudo apt clean                              # Remove pacotes baixados
sudo apt autoclean                          # Remove pacotes antigos

Resultado:
├─ Libera espaço em disco
├─ Seguro (pode baixar novamente se precisar)
└─ Típico: 500MB a 2GB liberados


LIMPAR CACHE DNF/YUM (RedHat/Fedora):
───────────────────────────────────────

sudo dnf clean all

Resultado:
├─ Mesma coisa que apt clean
├─ Libera 500MB a 2GB
└─ Seguro


LIMPAR CACHE PIP (Python):
────────────────────────

pip cache purge

Resultado:
├─ Remove arquivos Python baixados
├─ Tipicamente 100-300MB
└─ Seguro


LIMPAR CACHE NPM (Node.js):
────────────────────────────

npm cache clean --force

Resultado:
├─ Remove cache npm
├─ Tipicamente 100-500MB
└─ Seguro


═══════════════════════════════════════════════════════════════════════════════════
4. PASSO 2 - LIMPAR ARQUIVOS TEMPORÁRIOS
═══════════════════════════════════════════════════════════════════════════════════

LIMPAR /tmp:
─────────────

sudo rm -rf /tmp/*
sudo rm -rf /var/tmp/*

Resultado:
├─ Remove arquivos temporários do sistema
├─ Tipicamente 100MB-1GB
├─ Totalmente seguro
└─ Sistema cria novamente se precisar

⚠️ Não rodar se programas criticos estão salvando em /tmp


LIMPAR LIXEIRA (Trash):
───────────────────────

rm -rf ~/.local/share/Trash/*
rm -rf ~/.Trash/*

Resultado:
├─ Esvazia lixeira
├─ Tipicamente 100MB-5GB
├─ Seguro (estava pra deletar mesmo)
└─ Arquivos são permanentemente removidos


LIMPAR DOWNLOADS:
──────────────────

ls -lh ~/Downloads                          # Ver o que tem
du -sh ~/Downloads                          # Ver tamanho

Depois, remover:
rm ~/Downloads/*                            # Deletar tudo
ou manualmente:
rm ~/Downloads/arquivo-velho.iso            # Deletar específico


LIMPAR CACHE DO NAVEGADOR:

Firefox:
├─ Preferences → Privacy & Security
├─ Cookies and Site Data → Clear Data
├─ Ou: rm -rf ~/.mozilla/firefox/*/cache/

Chrome:
├─ Settings → Privacy and security → Clear browsing data
├─ Ou: rm -rf ~/.cache/google-chrome/


═══════════════════════════════════════════════════════════════════════════════════
5. PASSO 3 - LIMPAR LOGS ANTIGOS
═══════════════════════════════════════════════════════════════════════════════════

VER TAMANHO DE LOGS:
────────────────────

du -sh /var/log

Resultado:
2.5G    /var/log            ← Pode ser bem grande!


LIMPAR LOGS:
─────────────

sudo journalctl --vacuum=7d                 # Manter últimos 7 dias
ou
sudo journalctl --vacuum=100M                # Manter últimos 100MB

Resultado:
├─ Remove logs antigos
├─ Tipicamente libera 500MB-2GB
├─ Seguro (logs são histórico)
└─ Sistema cria novos normalmente

Ver quanto vai liberar:
sudo journalctl --disk-usage

ANTES: 2.5G
DEPOIS: 300M


LIMPAR /VAR/LOG:
─────────────────

sudo find /var/log -type f -name "*.gz" -delete    # Remove .gz comprimidos
sudo find /var/log -type f -name "*.1" -delete     # Remove logs rotacionados

ou simplesmente:
sudo truncate -s 0 /var/log/syslog                 # Zera arquivo de log

⚠️ Tome cuidado, pode precisar de sudo

6. PASSO 4 - DESATIVAR SERVIÇOS DESNECESSÁRIOS
═══════════════════════════════════════════════════════════════════════════════════

VER SERVIÇOS RODANDO:
─────────────────────

systemctl list-units --type=service --state=running | grep -v "loaded"

Resultado:
accounts-daemon.service
bluetooth.service
cups.service
... (muitos)

SERVIÇOS SEGUROS DE DESATIVAR (se não usa):
─────────────────────────────────────────────

Bluetooth (se não usa wireless):
sudo systemctl stop bluetooth
sudo systemctl disable bluetooth

Cups (impressora):
sudo systemctl stop cups
sudo systemctl disable cups

Avahi (descoberta de rede):
sudo systemctl stop avahi-daemon
sudo systemctl disable avahi-daemon

Colord (gerenciar cores):
sudo systemctl stop colord
sudo systemctl disable colord

GDPR/gdm (gerenciador de login):
├─ ❌ NÃO desative! Precisa para login

X11VNC (acesso remoto):
├─ Se não usa:
sudo systemctl stop vncserver
sudo systemctl disable vncserver


VERIFICAR SERVIÇO ANTES DE DESATIVAR:
──────────────────────────────────────

systemctl status [serviço]              # Ver o que faz

Se mostrar "inactive" = não está rodando


REATIVAR SE PRECISAR:
──────────────────────

sudo systemctl enable [serviço]
sudo systemctl start [serviço]

├─ Safe Browsing = Standard (menos uso de RAM)

├─ Memory saver = ON
├─ Battery saver = ON (se laptop)


DICAS GERAIS:
──────────────

├─ Limite de abas: máximo 10 abas abertas
├─ Remova extensões desnecessárias
├─ Desative notificações dos sites
├─ Limpe cache regularmente
└─ Reinicie navegador diariamente

10. PASSO 8 - OTIMIZAR DISCO
═══════════════════════════════════════════════════════════════════════════════════

VER ARQUIVOS GRANDES:
──────────────────────

du -sh ~/* | sort -rh | head -10

5.2G    /home/usuario/Videos
3.1G    /home/usuario/Downloads
2.4G    /home/usuario/.cache

─────────────────────

sudo apt install fdupes -y

────────────────────────

Depois delete:
find /home/usuario -type f -mtime +365 -size +100M -delete


COMPRIMIR ARQUIVOS ANTIGOS:
─────────────────────────────

tar -czf arquivo-velho.tar.gz /path/para/arquivos-antigos
rm -rf /path/para/arquivos-antigos

Resultado:
├─ Reduz para ~30% do tamanho original
├─ Libera muito espaço
├─ Ainda pode acessar se precisar

11. PASSO 9 - AUMENTAR VELOCIDADE INTERNET
═══════════════════════════════════════════════════════════════════════════════════

TESTAR VELOCIDADE ATUAL:
────────────────────────

speedtest-cli                               # Linha de comando
# ou
fast                                        # Mais simples

Instalar:
sudo apt install speedtest-cli -y

Rodar:
speedtest-cli --simple                      # Down / Up Mbps


OTIMIZAR DNS:
───────────────

DNS = Traduz google.com em IP

Editora:
sudo nano /etc/resolv.conf

Adicione (Google DNS - rápido):
nameserver 8.8.8.8
nameserver 8.8.4.4

ou (Cloudflare DNS - ainda mais rápido):
nameserver 1.1.1.1
nameserver 1.0.0.1

Ou via Network Settings:
├─ Settings → Network
├─ Wired/WiFi → DNS
├─ Manual: 8.8.8.8 e 8.8.4.4


VERIFICAR MTU:
──────────────

ip link show

Resultado:
eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500

1500 é padrão, está OK.

Se quer otimizar:
sudo ip link set dev eth0 mtu 1500           # Deixa padrão


DESATIVAR IPv6 (se não usa):
──────────────────────────────

sudo sysctl -w net.ipv6.conf.all.disable_ipv6=1
sudo sysctl -w net.ipv6.conf.default.disable_ipv6=1
sudo sysctl -w net.ipv6.conf.lo.disable_ipv6=1

Resultado:
├─ Mais rápido se IPv6 problemático
├─ Menos traffic
└─ Geralmente não muda nada (mantém ativado)

12. PASSO 10 - SWAPPINESS (USAR SSD COMO RAM)
═══════════════════════════════════════════════════════════════════════════════════

ENTENDER SWAP:

Swap = Usar disco como RAM quando RAM está cheia

⚠️ MUITO mais lento que RAM

Padrão: 60 (usa swap bastante)
Melhor: 10 (usa swap pouco)


VER SWAPPINESS ATUAL:
──────────────────────

cat /proc/sys/vm/swappiness

Resultado:
60              ← Valor padrão


REDUZIR SWAPPINESS:
────────────────────

sudo sysctl -w vm.swappiness=10

Resultado:
├─ Sistema prefere manter em RAM
├─ Usa swap só se absolutamente necessário
├─ Mais rápido se tiver RAM suficiente
└─ Sistema pode travarem falta de RAM

⚠️ Só faça se tiver 8GB+ de RAM


DEIXAR PERMANENTE:
───────────────────

sudo nano /etc/sysctl.conf

Adicione ao final:
vm.swappiness=10

Salve: Ctrl+O, Enter, Ctrl+X

13. SCRIPT COMPLETO DE LIMPEZA RÁPIDA
═══════════════════════════════════════════════════════════════════════════════════

CRIAR SCRIPT "MÁQUINA AVIÃO":
──────────────────────────────

cat > ~/airplane-mode.sh << 'EOF'
#!/bin/bash

echo "🚀 MÁQUINA AVIÃO - Otimizando Sistema..."

# 1. Sincronizar disco
echo "1. Sincronizando disco..."
sync

# 2. Limpar cache
echo "2. Limpando cache do sistema..."
sudo sysctl -w vm.drop_caches=3 > /dev/null

# 3. Limpar pacotes apt
echo "3. Limpando cache apt..."
sudo apt clean
sudo apt autoclean
sudo apt autoremove -y

# 4. Limpar /tmp
echo "4. Limpando arquivos temporários..."
sudo rm -rf /tmp/*
sudo rm -rf /var/tmp/*

# 5. Limpar lixeira
echo "5. Esvaziando lixeira..."
rm -rf ~/.local/share/Trash/*
rm -rf ~/.Trash/*

# 6. Limpar logs
echo "6. Limpando logs antigos..."
sudo journalctl --vacuum=7d > /dev/null

# 7. Limpar cache do navegador
echo "7. Limpando cache do navegador..."
rm -rf ~/.mozilla/firefox/*/cache/
rm -rf ~/.cache/google-chrome/Default/Cache/

# 8. Mostrar espaço liberado
echo ""
echo "✅ OTIMIZAÇÃO COMPLETA!"
echo ""
echo "Espaço em disco:"
df -h | grep -E '^/dev/'
echo ""
echo "Memória RAM:"
free -h | grep "^Mem"

EOF

chmod +x ~/airplane-mode.sh

Usar:
./airplane-mode.sh


VERSÃO COM MAIS LIMPEZA:
─────────────────────────

cat > ~/airplane-mode-aggressive.sh << 'EOF'
#!/bin/bash

echo "🚀 MÁQUINA AVIÃO AGRESSIVA..."

# Confirmação
read -p "Isso vai deletar TUDO desnecessário. Continuar? (s/n): " confirm
if [ "$confirm" != "s" ]; then
    echo "Cancelado"
    exit 1
fi

# Parar Firefox e Chrome
killall firefox chromium-browser chrome 2>/dev/null

# Limpeza agressiva
sudo sysctl -w vm.drop_caches=3
sudo apt clean
sudo apt autoclean
sudo apt autoremove -y
sudo rm -rf /tmp/*
sudo rm -rf /var/tmp/*
sudo rm -rf ~/.cache/*
rm -rf ~/.local/share/Trash/*
rm -rf ~/Downloads/*
sudo journalctl --vacuum=1d

# Desfragmentar (se não SSD)
# sudo e4defrag -c /dev/sda1

echo "✅ MÁQUINA LIMPISSIMA!"
df -h | grep -E '^/dev/'
free -h | grep "^Mem"

EOF

chmod +x ~/airplane-mode-aggressive.sh

────────────────────────

#!/bin/bash

LIMIT=80    # 80% de uso

USAGE=$(df / | tail -1 | awk '{print $5}' | cut -d'%' -f1)

if [ "$USAGE" -gt "$LIMIT" ]; then
    echo "⚠️  DISCO CHEIO! $USAGE% usado"
    echo "Rodando limpeza..."
    ~/airplane-mode.sh
else
    echo "✅ Disco OK: $USAGE% usado"
fi
EOF

chmod +x ~/check-disk.sh

Usar:
./check-disk.sh

──────────────────────────────

crontab -e

17. TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════

PROBLEMA: Máquina ainda está lenta
────────────────────────────────────

1. Verificar disco:
   df -h | grep -E '^/dev/'
   
   Se > 85%: rodá airplane-mode-aggressive.sh

2. Verificar memória:
   free -h | grep "^Mem"
   
   Se used > 80%: kill programas pesados (killer-process.txt)

3. Verificar processos:
   ps aux --sort=-%cpu | head -5
   
   Se algum > 50% CPU: matar com kill -9

4. Reiniciar:
   sudo reboot
   
   Muitos problemas resolvem com reboot


PROBLEMA: Firefox/Chrome comendo muita RAM
─────────────────────────────────────────

Kill e reabrir:
killall -9 firefox
firefox &

ou limpar cache:
rm -rf ~/.mozilla/firefox/*/cache/


PROBLEMA: Internet lenta mesmo depois de limpeza
──────────────────────────────────────────────

1. Testar velocidade:
   speedtest-cli --simple

2. Trocar DNS:
   sudo nano /etc/resolv.conf
   # Trocar por 8.8.8.8

3. Reiniciar modem/roteador:
   Desligar 10 segundos

4. Limpar cache navegador:
   Firefox: Settings → Privacy → Clear Data
   Chrome: Settings → Clear browsing data
