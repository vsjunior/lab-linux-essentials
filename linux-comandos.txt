1. DICAS ÚTEIS PARA COMEÇAR
═══════════════════════════════════════════════════════════════════════════════════

📌 OBTENDO AJUDA NO TERMINAL:

1. Digite qualquer comando seguido de "--help" para ver uma descrição detalhada
   Exemplo: wget --help

2. Use o comando "man" (manual) para documentação oficial
   Exemplo: man wget
           man ls
           man chmod

3. Para sair do manual, pressione a tecla "q"

⚠️ LEMBRE-SE: "Com grandes poderes, vem grandes responsabilidades!"
   Tenha cuidado ao executar comandos com privilégios de root.

2. NAVEGAÇÃO E MANIPULAÇÃO DE ARQUIVOS E PASTAS
═══════════════════════════════════════════════════════════════════════════════════

NAVEGAÇÃO:
──────────
cd /home                    # Vai para o diretório home
cd ..                       # Volta um nível de diretório
cd ../..                    # Volta 2 níveis
cd ~                        # Vai para o diretório de home do usuário atual
cd -                        # Volta para o diretório anterior
pwd                         # Mostra o caminho do diretório atual

LISTAGEM:
─────────
ls                          # Lista arquivos do diretório
ls -l                       # Lista com detalhes (permissões, tamanho, data)
ls -a                       # Mostra arquivos ocultos (começam com .)
ls -lh                      # Lista com tamanhos em formato legível (KB, MB, GB)
ls -lS                      # Lista ordenada por tamanho de arquivo
ls -lt                      # Lista ordenada por data de modificação
tree                        # Exibe arquivos em estrutura de árvore

CRIAÇÃO E REMOÇÃO:
──────────────────
mkdir nome_pasta            # Cria uma nova pasta
mkdir -p /tmp/dir1/dir2     # Cria estrutura completa de diretórios
touch arquivo.txt           # Cria um arquivo vazio ou atualiza sua data
rm arquivo.txt              # Remove um arquivo
rm -r pasta/                # Remove uma pasta e seu conteúdo
rm -rf pasta/               # Remove forçadamente (use com cuidado!)
rmdir pasta/                # Remove pasta vazia

CÓPIA E MOVIMENTO:
───────────────────
cp arquivo1.txt arquivo2.txt        # Copia arquivo
cp -r pasta1/ pasta2/               # Copia pasta com conteúdo
mv arquivo1.txt arquivo2.txt        # Move ou renomeia arquivo
mv arquivo1.txt /caminho/novo/      # Move arquivo para outro local

LINKS:
──────
ln -s arquivo link_simbólico        # Cria atalho (link simbólico)
ln arquivo link_fisico              # Cria link físico

grep -r "texto" ./          # Procura recursivamente em diretório

4. PERMISSÕES DE ARQUIVOS
═══════════════════════════════════════════════════════════════════════════════════

ENTENDENDO PERMISSÕES:
───────────────────────
Valores em octal:
  4 = leitura (r - read)
  2 = gravação (w - write)
  1 = execução (x - execute)

Exemplo: chmod 755 arquivo
  7 (4+2+1) = dono tem leitura, gravação, execução
  5 (4+1)   = grupo tem leitura e execução
  5 (4+1)   = outros têm leitura e execução

APLICANDO PERMISSÕES:
─────────────────────
chmod 755 arquivo           # rwxr-xr-x (padrão para scripts)
chmod 644 arquivo           # rw-r--r-- (padrão para arquivos de texto)
chmod 777 arquivo           # rwxrwxrwx (todos têm tudo - evitar!)
chmod 600 arquivo           # rw------- (somente o dono)
chmod +x arquivo            # Adiciona permissão de execução
chmod -w arquivo            # Remove permissão de gravação
chmod 755 -R pasta/         # Aplica permissões recursivamente em pasta

MUDANDO PROPRIETÁRIO:
──────────────────────
chown usuario arquivo       # Muda o proprietário
chown -R usuario pasta/     # Muda proprietário recursivamente
chgrp grupo arquivo         # Muda o grupo

5. INFORMAÇÕES DO SISTEMA
═══════════════════════════════════════════════════════════════════════════════════

SISTEMA:
────────

ESPAÇO EM DISCO:
────────────────
df -h                       # Mostra espaço em disco (formato legível)
du -sh diretório            # Mostra espaço usado por diretório
du -sh *                    # Mostra espaço de cada item no diretório atual

6. PROCESSA E MONITORAMENTO
═══════════════════════════════════════════════════════════════════════════════════

ps                          # Lista processos do usuário atual
ps aux                      # Lista todos os processos do sistema
top                         # Monitor em tempo real (q para sair)
htop                        # Versão melhorada do top
kill PID                    # Mata um processo pelo ID
killall nome_processo       # Mata todos os processos com este nome

fg                          # Traz trabalho para foreground

7. BUSCA DE ARQUIVOS
═══════════════════════════════════════════════════════════════════════════════════

locate arquivo              # Busca arquivo por nome (rápido)
find / -name arquivo        # Busca arquivo em todo o sistema
find . -name "*.txt"        # Busca arquivos .txt no diretório atual
find . -name "*.txt" -type f  # Busca apenas arquivos (não pastas)
find . -type d -name nome   # Busca apenas diretórios
find / -user usuario        # Busca arquivos de um usuário
which comando               # Mostra localização de um comando
whereis comando             # Mostra localização binária, fonte e manual


═══════════════════════════════════════════════════════════════════════════════════
8. COMPRESSÃO DE ARQUIVOS
═══════════════════════════════════════════════════════════════════════════════════

TAR (com ou sem compressão):
─────────────────────────────
tar -cf arquivo.tar pasta/          # Cria arquivo TAR
tar -xf arquivo.tar                 # Extrai arquivo TAR
tar -czf arquivo.tar.gz pasta/      # Cria TAR comprimido com gzip
tar -xzf arquivo.tar.gz             # Extrai TAR comprimido com gzip
tar -cjf arquivo.tar.bz2 pasta/     # Cria TAR comprimido com bzip2
tar -xjf arquivo.tar.bz2            # Extrai TAR comprimido com bzip2
tar -tzf arquivo.tar.gz             # Lista conteúdo sem extrair

GZIP:
──────
gzip arquivo                # Compacta arquivo (arquivo.gz)
gunzip arquivo.gz           # Descompacta arquivo
gzip -d arquivo.gz          # Descompacta arquivo (alternativa)

ZIP:
──────
zip -r arquivo.zip pasta/   # Cria arquivo ZIP
unzip arquivo.zip           # Extrai arquivo ZIP

────────────────

ssh-copy-id usuario@host    # Copia chave pública para host

DOWNLOAD:
──────────
wget url                    # Baixa arquivo de URL
wget -c url                 # Continua download interrompido
curl -O url                 # Alternativa ao wget

13. DICAS PRÁTICAS E COMANDOS ÚTEIS
═══════════════════════════════════════════════════════════════════════════════════

LIMPEZA DO SISTEMA:
─────────────────────
rm -rf ~/.cache/*           # Limpa cache do usuário
apt clean                   # Remove pacotes baixados (Debian/Ubuntu)
apt autoclean               # Remove pacotes não necessários
dnf clean all               # Remove cache de pacotes (Fedora/RHEL)

BUSCAS AVANÇADAS:
──────────────────
grep -r "texto" diretório   # Busca recursiva
grep -i "texto" arquivo     # Busca ignorando maiúsculas/minúsculas
grep -c "texto" arquivo     # Conta ocorrências
find . -mtime -7            # Encontra arquivos modificados nos últimos 7 dias
find . -size +100M          # Encontra arquivos maiores que 100MB

MANIPULAÇÃO DE TEXTO:
──────────────────────
cat arquivo | wc -l         # Conta linhas de arquivo
sort arquivo                # Ordena linhas
uniq arquivo                # Remove linhas duplicadas
cut -d: -f1 arquivo         # Recorta colunas
awk '{print $1}' arquivo    # Processa dados em colunas
sed 's/velho/novo/g' arquivo  # Substitui texto

MONITORAMENTO:
───────────────
tail -f /var/log/syslog     # Monitora log do sistema
dmesg                       # Mostra mensagens do kernel
journalctl -xe              # Mostra log de inicialização

DICAS DE PRODUTIVIDADE:
────────────────────────
history                     # Mostra histórico de comandos
clear                       # Limpa a tela
alias ll='ls -lh'           # Cria atalho de comando
man -k termo                # Busca comandos relacionados
echo "texto" > arquivo      # Cria arquivo com conteúdo
cat arquivo1 arquivo2 > arquivo3  # Junta dois arquivos

CONTROLE DE ACESSO:
─────────────────────
sudo -l                     # Lista comandos que pode executar com sudo
sudo -u usuario comando     # Executa como outro usuário
sudo visudo                 # Edita arquivo sudoers com segurança

15. EXEMPLOS PRÁTICOS DO DIA A DIA
═══════════════════════════════════════════════════════════════════════════════════

# Criar backup de um diretório
tar -czf backup_$(date +%Y%m%d).tar.gz /caminho/para/diretorio

# Encontrar os 10 maiores arquivos do sistema
find / -type f -printf '%s %p\n' | sort -rn | head -10

# Contar quantos arquivos em um diretório
ls -1 | wc -l

# Remover arquivos antigos (mais de 30 dias)
find /caminho -type f -mtime +30 -delete

# Monitorar uso de CPU em tempo real
watch -n 1 'ps aux | sort -nrk 3,3 | head -10'

# Sincronizar duas pastas
rsync -avz /origem/ /destino/

# Procurar e substituir em múltiplos arquivos
sed -i 's/velho/novo/g' *.txt

# Ver quanto espaço cada pasta ocupa
du -sh /* | sort -rh

# Extrair arquivo ZIP com segurança
unzip -d destino/ arquivo.zip

# Criar arquivo com linhas numeradas
nl arquivo.txt

# Acompanhar espaço em disco em tempo real
watch -n 60 'df -h'
